# Катания 1905: Историческая база знаний (Catania 1905)

> [!abstract] Описание хранилища
> Комплексная структурированная база знаний, документирующая историю, экономику, социально-политический уклад, градостроительство и культуру города Катания (Сицилия, Королевство Италия) в 1905 году. Данный период представляет собой зенит эпохи Belle Époque («Милан Юга»), совпавший с масштабными урбанистическими реформами муниципального социализма, вводом электрического трамвая, зарождением сицилийского модерна (Stile Liberty) и тектоническими изменениями в мировой и региональной экономике.

## Архитектура базы знаний и принципы организации

1. **Минималистичный дизайн**: Отсутствие эмодзи и декоративных иконок; структурирование информации за счет выверенной типографики, таблиц, списков определений и цитатных блоков.
2. **Семантическая связность**: Полная двунаправленная перекрестная перелинковка заметок через синтаксис внутренних ссылок Obsidian (двойные квадратные скобки вокруг имени файла или с указанием псевдонима через вертикальную черту).
3. **Метаданные YAML**: Унифицированные поля `tags`, `type`, `created`, `updated`, `aliases` во всех документах для совместимости с плагинами Dataview и фильтрацией Obsidian.
4. **Интерактивный граф**: Хранилище оптимизировано для работы с Graph View (`Ctrl+G` / `Cmd+G`), формируя плотный информационный граф без тупиковых или изолированных узлов.
