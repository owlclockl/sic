# Reveal Atlas

Веб-приложение: карта мира, поделённая на ровные квадраты, которые открываются по мере
прохождения. Мир — это обычная картинка (PNG/JPEG/WebP/AVIF/GIF/BMP любого разрешения),
а размер квадратов настраивается под неё.

![grid](https://img.shields.io/badge/grid-tile%20%7C%20columns-7ee0c3) ![stack](https://img.shields.io/badge/React%2018%20%2B%20Vite%20%2B%20TS-0b1220)

## Возможности

- **Сетка под любое разрешение.** Два режима:
  - *В пикселях* — сторона квадрата задаётся в пикселях исходной картинки (8–512),
    с пресетами 16/24/32/48/64/96/128.
  - *По колонкам* — задаётся количество клеток по ширине мира (4–200). Полезно, когда
    картинки приходят в разных разрешениях: клетка всегда одна и та же доля карты.
  - Сдвиг сетки по X/Y, чтобы совместить линии с границами регионов.
  - Показано итоговое число клеток и размер стороны в пикселях исходника.
- **Открытие «по мере прохождения».** Кисть 1×1…5×5, инструмент «Открыть», «Скрыть»
  (или ПКМ) и «Рука». Прогресс в процентах и клетках, `Ctrl+Z` — отмена.
- **Зум и панорама**: колесо мыши (зум к курсору), Shift+перетаскивание, тач-пинч,
  кнопка «вписать», `F`.
- **Несколько миров**: список проектов с миниатюрами и прогрессом, создание из файла,
  drag&drop картинки на карту, замена картинки, удаление, переименование.
- **Сохранение**: в браузере данные хранятся в `IndexedDB` (с резервным `localStorage`), а при
  запуске через `RevealAtlas.cmd` — напрямую на диске ПК без ограничений браузера по объёму.
  Прогресс кодируется base64-маской (1 бит на клетку), поэтому 100 000 клеток — это ~17 КБ.
- **Запуск на ПК одним файлом (`RevealAtlas.cmd`)**: полностью автономный файл для Windows 10/11
  без установки Node.js или сторонних программ — открывается в отдельном окне приложения без
  вкладок и адресной строки.
- **Экспорт/импорт проекта в JSON** — можно перенести мир на другое устройство.
- **Телефон** — отдельная мобильная раскладка: нижняя панель инструментов вместо верхней,
  шторки «Миры» и «Настройки» с затемнением фона, крупные кнопки и поля, безопасные зоны
  iPhone, работа одним пальцем. Подробнее — в разделе «Телефон».
- При первом запуске создаётся **демо-мир** (процедурная карта), чтобы сразу было что открывать.

## Запуск одним файлом на ПК (Windows)

В корне проекта находится готовый самодостаточный файл **`RevealAtlas.cmd`** (~139 КБ).
Его можно скопировать куда угодно (на Рабочий стол, в любую папку или на флешку) — другие
файлы из репозитория, интернет или Node.js для его работы **не нужны**.

1. Скачайте только один файл `RevealAtlas.cmd`.
2. Запустите его двойным кликом.
3. Откроется отдельное окно программы **Reveal Atlas** (без вкладок и адресной строки браузера,
   с собственной иконкой и тёмной рамкой окна). Когда вы закрываете окно, фоновый локальный
   мини-сервер автоматически завершает работу.

### Что умеет режим программы на ПК

- **Автосохранение на диске без лимита 5 МБ**: все миры и карты высокого разрешения (до 64 МБ
  и 8192 px по длинной стороне) сохраняются в `%LOCALAPPDATA%\RevealAtlas`.
- **Портативный режим (на флешке)**: запустите `RevealAtlas.cmd --portable` (или создайте рядом
  папку `RevealAtlas-Data`) — тогда все сохранения будут храниться прямо рядом с файлом.
- **Ярлык с фирменной иконкой**: в правом меню «Настройки → Программа на ПК» есть кнопки
  «Создать ярлык на Рабочем столе» и «Открыть папку сохранений».
- **Распаковка автономного `.html`**: команда `RevealAtlas.cmd --export-html` сохраняет рядом
  один самодостаточный файл `RevealAtlas.html`, который можно открыть в любом браузере офлайн.

### Если окно программы не открывается

Окно программы — это отдельное окно Chromium-браузера (Edge, Chrome, Яндекс.Браузер, Brave,
Vivaldi, Opera), который уже есть в системе: свой движок в `RevealAtlas.cmd` не входит.
Поэтому запуск окна зависит от того, исправен ли браузер на компьютере.

Что делает запускалка:

1. Находит **все** установленные Chromium-браузеры (реестр `App Paths` + стандартные папки).
2. Пробует открыть окно по очереди и **проверяет, что окно действительно подключилось**
   к локальному серверу. Браузер, который не стартует (например, из-за поломанного
   манифеста зависимостей Windows), пропускается — берётся следующий.
3. Если ни один браузер не подошёл, открывает адрес системным браузером по умолчанию.
4. Только если не сработало ничего, показывает окно с объяснением, списком попыток и
   адресом, который можно открыть вручную. Мини-сервер при этом продолжает работать,
   так что прогресс не теряется.

**Ошибка Windows «The application has failed to start because its side-by-side configuration
is incorrect» (код 14001).** Она относится к самому браузеру, а не к Reveal Atlas: у него
повреждён или не обновлён манифест зависимостей (`Microsoft.VC*.CRT`). Что делать:

- обновить браузер: в Edge — `edge://settings/help`, в Chrome — `chrome://settings/help`;
- если Edge «застрял» на середине обновления, в папке
  `C:\Program Files (x86)\Microsoft\Edge\Application\` может лежать `new-msedge.exe` —
  запустите его вручную, он доведёт обновление до конца;
- переустановить Microsoft Edge или установить Google Chrome / Яндекс.Браузер:
  после переустановки `RevealAtlas.cmd` подхватит рабочий браузер сам;
- подробности ошибки — в журнале «Просмотр событий → Журналы Windows → Приложение»
  (источник `SideBySide`) или через `sxstrace.exe`;
- диагностика запуска: `RevealAtlas.cmd --debug` — команда печатает, какие браузеры
  проверялись и что произошло с каждым.

## Разработка и пересборка

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production-сборка в dist/ + обновление RevealAtlas.cmd
npm run build:single # то же самое: пересобрать единый файл RevealAtlas.cmd
npm run preview
npm run typecheck
```

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `1` / `2` / `3` | Открыть / Скрыть / Рука |
| `[` `]` | Размер кисти |
| `G` | Показать сетку |
| `F` | Вписать мир в окно |
| `Ctrl+Z` | Отменить последний мазок |
| Колесо | Зум к курсору |
| ПКМ | Стирать (скрывать) клетки |
| Shift + перетаскивание | Панорама |

## Телефон

На экранах до 980 px интерфейс перестраивается под палец:

| Элемент | Как работает |
| --- | --- |
| Нижняя панель | Прогресс (`12% · 45 / 400`) + крупные «Открыть / Скрыть / Рука» + «Кисть», «Отмена», «Сетка», «Вписать», «Настройки» |
| «Миры» | Кнопка ☰ в шапке открывает левую шторку со списком миров |
| «Настройки» | Нижняя шторка: размер квадратов, сдвиг сетки, прогресс, картинка |
| Фон шторки | Затемнение: тап по нему или по карте закрывает шторку |
| Один палец | Тап — открыть одну клетку, свайп — открывать по ходу движения |
| Два пальца | Зум и панорама одновременно; случайный мазок при пинче не ставится |
| Кисть | Кнопка «Кисть» переключает 1×1 → 2×2 → 3×3 → 5×5 |
| Безопасные зоны | Учитываются `safe-area-inset` (вырез, home-индикатор) |

При первом открытии на телефоне показывается подсказка по жестам — она исчезает
после первого мазка или по кнопке «Понятно» и больше не появляется.

Что специально учтено в коде: касание не закрашивает клетку мгновенно (иначе при пинче
ставился бы лишний мазок) — одиночный тап открывает клетку на отпускании; двойной тап
на тач-экранах не зумит; поля ввода набраны 16 px, чтобы iOS не масштабировал страницу;
`touch-action: none` на карте отключает прокрутку/перетягивание страницы.

## Как устроено

```
src/
  lib/
    grid.ts        геометрия сетки: режимы «пиксели» и «колонки», сдвиги, координаты клеток
    bits.ts        маска открытых клеток: Uint8Array, base64-кодирование, ресайз
    projects.ts    модель проекта, нормализация импорта, экспорт
    storage.ts     хранилище: локальный диск ПК (RevealAtlas.cmd), IndexedDB и localStorage
    image.ts       чтение файла, проверки, даунскейл больших картинок
    demoWorld.ts   процедурный демо-мир
  components/
    MapView.tsx    карта: туман, кисть, зум/панорама, тач-жесты, отрисовка на canvas
    Sidebar.tsx    список миров
    SettingsPanel.tsx  настройки размера квадратов, прогресса, картинки
  App.tsx          состояние, автосохранение, undo, импорт/экспорт
```

Ключевая идея: сетка не привязана к разрешению картинки жёстко. Конфиг сетки хранит
режим и параметр (`tileSize` в пикселях или `columns`), а `computeGrid()` пересчитывает
`cols × rows` под текущую картинку. При изменении размера клеток маска прогресса
переносится в новую сетку (по индексам, от левого верхнего угла), так что уже открытые
участки не теряются.

## Ограничения

- Принимаются изображения до 64 МБ; слишком огромные холсты автоматически приводятся к
  8192 px по длинной стороне в режиме ПК (6144 px в настольном браузере, 4096 px на телефоне).
- Анимации открытия клеток пока нет — прогресс применяется мгновенно.
